# 报告扩充的分析设计

## 比较范围与采用角度

本轮比较本地课程报告的方法组织和分析角度。其他作业的任务数据、模型结论、实测结果和案例不作为本实验结果使用，也不将其段落转写为本报告正文。

| 课程材料 | 本轮考察的角度 | 在 Java 文件合成实验中的对应问题 |
|---|---|---|
| 作业 1.3：n-gram | 用中间统计解释整体指标；明确统计单位 | 将文件提取、可观察测试阶段与全部关联命令通过分开描述 |
| 作业 1.5：PyTorch NLL | 概率目标与输入/标签位置之间的关系 | 解释源码响应掩码、下一词元标签对齐及损失分母 |
| 作业 2.1：词向量实验 | 数据分布与分析对象的界定 | 统计 Java 样本的源码行数、提示和骨架字符长度 |
| 作业 3.1：BERT 标点恢复 | 序列预处理、掩码与任务目标的联系 | 区分提示条件、源码监督、截断、填充与样本打包 |
| 作业 3.2：NextBERT | 分层诊断与机制解释的分工 | 按固定预测的文件规模和评测阶段分析结果，避免因果扩张 |
| 作业 4.1：提示词泄漏 | 阶段性结果与最终成功的区分 | 从实际命令日志确认测试阶段可见性，不用首因标签替代阶段证据 |
| 作业 4.2：诗词英译 | 样本长度及任务属性对结果解释的作用 | 描述长短文件结果及仓库组成，不将长度等同业务复杂度 |
| 作业 5.1：后训练综述 | 区分训练信号、评价指标与能力判断 | 说明测试只用于筛选和离线评价；监督损失仅来自源码词元 |
| 作业 5.2：后训练实验 | 目标、数据、实现语义与诊断指标形成闭环 | 说明实际全参数配方、损失归约、梯度日志和功能比较的关系 |
| 作业 6 | 结合任务对象组织错误与案例分析 | 用真实 Java 文件的跨方法状态约束组织完整业务案例 |

## 内容边界

正文中的新定量结果来自本作业已归档的训练索引、训练事件统计、原始评测 JSON 与命令日志。补充程序只做离线解析与绘图，不重新调用模型、构造训练样本或运行原工程测试。

训练曲线对应领域微调训练版本 V4；功能结果对应历史版本 0826 的保存预测。二者不建立未经确认的检查点映射。Java 数据分布统计不用于改写完整训练运行中的实际语言构成。

ClassEval 的任务定位依据 Du 等发表于 ICSE 2024 的论文《Evaluating Large Language Models in Class-Level Code Generation》：https://mingwei-liu.github.io/assets/pdf/ICSE2024ClassEval-V2.pdf 。本报告仅用其说明输出粒度和成员依赖，与本实验通过率不作数值比较。

新增统计的字段、计算口径及逐项核对保存在 [data_expansion_notes.md](../materials/data_construction/analysis/data_expansion_notes.md)、[training_expansion_notes.md](training_expansion_notes.md) 和 [evaluation_expansion_notes.md](evaluation_expansion_notes.md)；正文仅保留理解方法、统计对象、结果和适用范围所需的信息。

正文整合后含 12 幅图、13 张表和 16 项参考文献。已有仓库结果叙述中的 yudao-cloud 基线数已按两份原始报告更正为 0/4→1/4。新增阶段解析明确区分至少一条测试任务有结果、非缓存执行记录和全部命令成功；缓存任务不被描述为当次重新执行。
